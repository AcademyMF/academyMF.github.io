# 🎓 AcademyMF

Bienvenidos al repositorio oficial de **AcademyMF**. Esta es la base de nuestra plataforma educativa, donde combinamos tecnología, divulgación y aprendizaje.

## 🚀 Sobre el Proyecto
AcademyMF es un espacio diseñado para compartir conocimiento a través de:
- ✍️ Artículos y Blog de divulgación.
- 📺 Clases grabadas y material audiovisual.
- 📚 Apuntes y recursos descargables.

## 🛠️ Estructura del Repositorio
- `index.html`: Portal principal (Borrador actual).
- `/assets`: Recursos visuales, imágenes y estilos CSS.
- `/blog`: Contenido de artículos (próximamente).
